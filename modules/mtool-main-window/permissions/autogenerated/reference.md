| Permission | Description |
|------|-----|
|`allow-exec-command`|Enables the exec_command command without any pre-configured scope.|
|`deny-exec-command`|Denies the exec_command command without any pre-configured scope.|
|`allow-get-hotkeys`|Enables the get_hotkeys command without any pre-configured scope.|
|`deny-get-hotkeys`|Denies the get_hotkeys command without any pre-configured scope.|
|`default`|Default permissions for the plugin.|
